# A scuola in Italia

Italian 2 activity (Novice High to Intermediate Low): how school works in Italy.

Eight steps, about two class periods plus homework: learn 16 school words and essere / avere / -are verbs, read three short paragraphs, check understanding (true/false with corrections and short answers), complete sentences, compare with a same/different organizer, a research mini-project, and a one-paragraph comparison with a model, rubric, and live checklist.

Student work is saved only in the browser on the student's device. Names are never saved.

Live: https://appuccinohub.github.io/a-scuola-in-italia/
